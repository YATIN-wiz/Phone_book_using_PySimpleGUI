PhoneBook Application - FreeSimpleGUI + SQLite
=============================================
A fully functional contact manager with CRUD, search, and data persistence.
A "Contacts.db" SQLite file will be created automatically in the same folder.


Features:
- Add new contacts with name, phone, and email.
- Search contacts by name (case-insensitive, partial matches).
- View contact details, edit or delete them.
- Browse all contacts in a table.
Data Validation:
- Name and phone are required fields.
- Phone must contain only digits and common formatting characters.
- Email is optional but must be a valid email address if provided.
